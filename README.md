# P6 Schedule Health Checker

**Primavera P6 XER | Python | DCMA 14-Point Schedule Integrity Assessment**

## Overview

A planned Python-based workflow for assessing Primavera P6 XER schedule integrity using DCMA 14-point criteria. The repository is intended to support transparent schedule health checks, reproducible analysis, and project controls reporting using synthetic project data.

**Project status:** Repository scaffold. Assessment logic, automated tests, and validated results have not yet been published.

## Planned Scope

- Parse and examine Primavera P6 XER schedule exports.
- Evaluate applicable schedule health indicators against defined DCMA 14-point assessment criteria.
- Document assessment assumptions, exclusions, and interpretation rules.
- Produce traceable reports and test results using synthetic data.
